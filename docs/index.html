Livestream highlights, turned into vertical clips.

DOGSAPKA AI Clipper is a desktop application for Windows and macOS. It watches livestreams that the user owns or is authorized to use, detects exciting moments, cuts them into subtitled 9:16 clips and - only when the user chooses - uploads them to the user's own YouTube and TikTok accounts.

Download Privacy Policy

Highlight detection

Chat activity, chat reactions, audio and video signals - processed locally on the user's computer.

Automatic editing

Facecam on top, gameplay below, subtitles, export in TikTok / YouTube Shorts format.

Upload with consent

Videos are uploaded only to accounts the user connected, only after the user chooses to do so.

Runs on your computer

No DOGSAPKA server: recordings, clips, settings and tokens stay on the user's own device.

How TikTok is used

With TikTok Login Kit the user connects their own TikTok account inside the app (permission user.info.basic, used only to show which account is connected). With the Content Posting API (video.upload) a clip the user selected is sent to that account's TikTok inbox, where the user reviews it and publishes it in the TikTok app.
